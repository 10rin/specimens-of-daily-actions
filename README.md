# 生活所作標本 / 生活合理所作標本
**Specimens of Daily Actions / Specimens of Optimized Daily Actions**

効率化で消えていく暮らしの手触りを、MP3アルバムとして標本にする。

▶ **ページを開く**: https://10rin.github.io/specimens-of-daily-actions/

---

## 作品について

掃除、支払い、湯を沸かす、コーヒーを淹れる、書く、火を灯す、音楽を聴く。日々繰り返す7つの所作を、合理化される前の方法と、合理化された現在の方法の2通りで録音し、2枚のMP3アルバムとして残した。

技術が進むほど、暮らしの行為は短く、静かになっていく。ほうきで掃いて塵を集めて捨てていた一連の動作は掃除機の「吸う」ひとつになり、小銭を数えて払っていた手間はスマートフォンを「かざす」だけになった。便利になった一方で、行為の途中にあった手触りや音、時間には気づかなくなっている。

人は結果だけでなく、そこに至るプロセスにも価値を感じている。合理化で消えつつある所作を「標本」として残し、その価値に改めて気づくきっかけをつくる。

We recorded seven everyday actions—cleaning, paying, boiling, brewing, writing, lighting, and listening—in two ways: the way they were done before optimization, and the way they are done today. As technology advances, everyday actions become shorter and quieter, and we no longer notice the textures, sounds, and time that were part of them. Believing that people value not only outcomes but also the process, we preserved these disappearing actions as "specimens."

## このページについて

2枚のアルバムを、同期歌詞つきで聴くためのページ。

- アルバムを選んで再生する（シャッフル、曲送り、自動で次の曲へ）
- 再生に合わせて、今行っている所作の手順が表示される。手順をクリックすると、その時点から聴ける
- Mac・PCでは右に歌詞、スマホでは歌詞を全画面で表示する
- URLの最後に `#d01`〜`#d07`（生活所作標本）、`#o01`〜`#o07`（生活合理所作標本）をつけると、その曲を選んだ状態で開く
